## Configuration

Add to your `claude_desktop_config.json` (Claude Desktop) or your MCP client config:

```json
{
  "mcpServers": {
    "inventory-management-ai-mcp": {
      "command": "uvx",
      "args": ["inventory-management-ai-mcp"]
    }
  }
}
```

Or: `pip install inventory-management-ai-mcp` then run the `inventory-management-ai-mcp` command (stdio transport).
